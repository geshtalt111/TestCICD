ШПАРГАЛКА ПО C#: ПРОГРАММА, ОТЛАДКА И ТЕСТЫ

============================================================
1. ПРОСТАЯ ПРОГРАММА НА C# С ДВУМЯ КЛАССАМИ
============================================================

using System;
using System.Diagnostics;

class Program
{
    // Класс Calculator хранит логику программы
    // В нем находятся методы, которые выполняют действия
    class Calculator
    {
        public int Add(int a, int b)
        {
            Debug.WriteLine($"Вызван метод Add: {a} + {b}");

            int result = a + b;

            Debug.WriteLine($"Результат сложения: {result}");

            return result;
        }

        public int Multiply(int a, int b)
        {
            Debug.WriteLine($"Вызван метод Multiply: {a} * {b}");

            int result = a * b;

            Debug.WriteLine($"Результат умножения: {result}");

            return result;
        }

        public int Divide(int a, int b)
        {
            Debug.WriteLine($"Вызван метод Divide: {a} / {b}");

            if (b == 0)
            {
                Debug.WriteLine("Ошибка: попытка деления на ноль");
                throw new DivideByZeroException("Делить на ноль нельзя");
            }

            int result = a / b;

            Debug.WriteLine($"Результат деления: {result}");

            return result;
        }
    }

    // Main — это точка входа в программу
    // Программа начинает выполняться именно отсюда
    static void Main(string[] args)
    {
        Calculator calc = new Calculator();

        int sum = calc.Add(10, 5);
        int mult = calc.Multiply(4, 3);
        int div = calc.Divide(20, 4);

        Console.WriteLine("Сумма: " + sum);
        Console.WriteLine("Умножение: " + mult);
        Console.WriteLine("Деление: " + div);

        Console.ReadKey();
    }
}


============================================================
2. КАК ПОНЯТЬ СТРУКТУРУ ПРОГРАММЫ
============================================================

class Program
{
    class Calculator
    {
        // Здесь пишутся методы
    }

    static void Main(string[] args)
    {
        // Здесь создается объект класса
        // Здесь вызываются методы
    }
}

Главная идея:

1. В верхней части пишется класс с логикой.
2. Внутри класса создаются методы.
3. Внизу пишется Main.
4. В Main создается объект класса.
5. Через объект вызываются методы.

Пример:

Calculator calc = new Calculator();

Это значит:
мы создали объект calc на основе класса Calculator.

Пример вызова метода:

int result = calc.Add(5, 3);

Это значит:
у объекта calc вызывается метод Add, в него передаются числа 5 и 3.


============================================================
3. СПОСОБЫ ОТЛАДКИ В C#
============================================================

Отладка нужна, чтобы найти ошибки в программе и понять, как она работает.

------------------------------------------------------------
СПОСОБ 1. Console.WriteLine()
------------------------------------------------------------

Самый простой способ — выводить значения в консоль.

Пример:

int a = 10;
int b = 5;

Console.WriteLine("a = " + a);
Console.WriteLine("b = " + b);
Console.WriteLine("Сумма = " + (a + b));

Так можно проверить, какие значения хранятся в переменных.

------------------------------------------------------------
СПОСОБ 2. Debug.WriteLine()
------------------------------------------------------------

Для этого нужно подключить:

using System.Diagnostics;

Пример:

Debug.WriteLine("Программа дошла до этого места");

Debug.WriteLine выводит сообщения в окно Output / Вывод в режиме Debug.

Пример в методе:

public int Add(int a, int b)
{
    Debug.WriteLine($"Складываем {a} и {b}");

    int result = a + b;

    Debug.WriteLine($"Результат: {result}");

    return result;
}

------------------------------------------------------------
СПОСОБ 3. Breakpoint / точка останова
------------------------------------------------------------

Breakpoint — это точка, где программа останавливается во время выполнения.

Как поставить:
1. Нажать слева от строки кода.
2. Появится красная точка.
3. Запустить программу в Debug.
4. Программа остановится на этой строке.

После остановки можно смотреть:
- значения переменных;
- какие методы вызвались;
- где находится ошибка.

------------------------------------------------------------
СПОСОБ 4. Step Over
------------------------------------------------------------

Step Over — выполнить текущую строку и перейти к следующей.

Используется, когда не нужно заходить внутрь метода.

------------------------------------------------------------
СПОСОБ 5. Step Into
------------------------------------------------------------

Step Into — зайти внутрь метода.

Например, если есть строка:

int sum = calc.Add(10, 5);

Step Into зайдет внутрь метода Add.

------------------------------------------------------------
СПОСОБ 6. Step Out
------------------------------------------------------------

Step Out — выйти из текущего метода обратно туда, откуда он был вызван.

------------------------------------------------------------
СПОСОБ 7. Watch / окно наблюдения
------------------------------------------------------------

В Watch можно добавить переменную и смотреть, как меняется ее значение.

Например:
a
b
result

------------------------------------------------------------
СПОСОБ 8. Проверка исключений
------------------------------------------------------------

Если программа падает, можно посмотреть, где именно возникла ошибка.

Пример:

if (b == 0)
{
    throw new DivideByZeroException("Делить на ноль нельзя");
}

Это значит:
если b равно 0, программа специально выбрасывает ошибку.

4. КЛАСС ДЛЯ ТЕСТОВ MSTest
============================================================

Для тестов обычно создается отдельный проект тестов.

Пример класса с тестами:

using Microsoft.VisualStudio.TestTools.UnitTesting;

namespace CalculatorTests
{
    [TestClass]
    public class CalculatorTest
    {
        [TestMethod]
        public void Add_10And5_Returns15()
        {
            // Arrange — подготовка данных
            Calculator calc = new Calculator();

            // Act — выполнение действия
            int result = calc.Add(10, 5);

            // Assert — проверка результата
            Assert.AreEqual(15, result);
        }

        [TestMethod]
        public void Multiply_4And3_Returns12()
        {
            Calculator calc = new Calculator();

            int result = calc.Multiply(4, 3);

            Assert.AreEqual(12, result);
        }

        [TestMethod]
        public void Divide_20And4_Returns5()
        {
            Calculator calc = new Calculator();

            int result = calc.Divide(20, 4);

            Assert.AreEqual(5, result);
        }

        [TestMethod]
        public void Divide_ByZero_ThrowsException()
        {
            Calculator calc = new Calculator();

            Assert.ThrowsException<DivideByZeroException>(() =>
            {
                calc.Divide(10, 0);
            });
        }
    }
}


============================================================
5. ВАЖНО ДЛЯ ТЕСТОВ
============================================================

[TestClass]
означает, что это класс с тестами.

[TestMethod]
означает, что это отдельный тест.

Assert.AreEqual(expected, actual)
сравнивает ожидаемый результат и фактический результат.

Пример:

Assert.AreEqual(15, result);

15 — это то, что мы ожидаем.
result — это то, что реально вернул метод.

Assert.ThrowsException
проверяет, что метод выбрасывает ошибку.

Пример:

Assert.ThrowsException<DivideByZeroException>(() =>
{
    calc.Divide(10, 0);
});


============================================================
6. ВАЖНОЕ ЗАМЕЧАНИЕ
============================================================

Если класс Calculator находится внутри класса Program, то в тестах напрямую вызвать Calculator может быть неудобно.

Для тестов лучше делать Calculator отдельным классом:

public class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }
}

А Program отдельно:

class Program
{
    static void Main(string[] args)
    {
        Calculator calc = new Calculator();
        Console.WriteLine(calc.Add(5, 3));
    }
}

Так тестировать проще, потому что тестовый проект сможет видеть класс Calculator.


============================================================
7. САМАЯ ПРОСТАЯ СТРУКТУРА ДЛЯ ЗАПОМИНАНИЯ
============================================================

public class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }
}

class Program
{
    static void Main(string[] args)
    {
        Calculator calc = new Calculator();

        int result = calc.Add(5, 3);

        Console.WriteLine(result);
    }
}

Запомнить можно так:

1. Сначала пишем класс с методами.
2. Потом пишем Program.
3. Внутри Program пишем Main.
4. В Main создаем объект.
5. Через объект вызываем методы.
